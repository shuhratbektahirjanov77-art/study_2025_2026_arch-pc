2.5 Права доступа к файлам и каталогам

Права доступа определяют, кто может читать (r), записывать (w) и выполнять (x) файл.

Просмотр прав доступа:
bash

ls -l

Рисунок 15 — Просмотр прав доступа

Расшифровка прав доступа:
Символ	Значение
-	файл
d	каталог
r	чтение
w	запись
x	выполнение

Пример: -rw-r--r-- означает:

    - — это файл

    rw- — владелец может читать и писать

    r-- — группа может только читать

    r-- — остальные могут только читать

4. Контрольные вопросы
1. Какие команды используются для создания текстовых файлов?

touch имя_файла — создаёт пустой файл.
2. Какие команды используются для просмотра файлов?

    cat — просмотр всего файла

    less — постраничный просмотр

    head — первые строки (по умолчанию 10)

    tail — последние строки (по умолчанию 10)

3. Какие команды используются для копирования файлов и каталогов?

    cp — копирование файлов

    cp -r — рекурсивное копирование каталогов

4. Какие команды используются для перемещения и переименования?

mv — перемещение и переименование файлов и каталогов.
5. Что такое права доступа?

Права доступа — это механизм, определяющий, кто может читать (r), записывать (w) и выполнять (x) файл или каталог.
6. Как изменить права доступа?

Команда chmod:

    chmod u+x файл — добавить выполнение для владельца

    chmod g-w файл — убрать запись для группы

    chmod o=r файл — установить только чтение для остальных

    chmod 755 файл — установить права (rwxr-xr-x)
